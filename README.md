# nodejs-heroku-explorer

A Node.js app using [Express](https://expressjs.com/)

# Running Locally

Make sure you have [Node.js](https://nodejs.org/)

```sh
$ git clone https://github.com/guanguer/nodejs-heroku-explorer.git
$ cd nodejs-heroku-explorer
$ npm install
$ npm start
```

Your app should now be running on [localhost:3000](http://localhost:3000/).

# Running Tests

```sh
$ npm test
```
